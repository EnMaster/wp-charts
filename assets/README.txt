Graphista — Store assets (wordpress.org)
========================================

This folder is NOT part of the plugin ZIP. For the WordPress.org plugin
page you must commit these images into the `/assets/` directory of the
plugin's SVN repository (sibling of `/trunk/` and `/tags/`).

Required files
--------------

Icon (plugin icon on wordpress.org):
  icon-128x128.png      128 x 128 px
  icon-256x256.png      256 x 256 px

Banner (plugin page header):
  banner-772x250.png    772 x 250 px  (retina: 1544 x 500 px)
  banner-1544x500.png   1544 x 500 px

Screenshots (referenced in readme.txt):
  screenshot-1.png      Widget settings in the Elementor editor
  screenshot-2.png      Bar chart rendered on the frontend
  screenshot-3.png      Pie chart rendered on the frontend
  screenshot-4.png      Line chart rendered on the frontend

Tips
----

* Keep the "Screenshots" section of readme.txt in sync with the number
  and order of screenshot-N.png files.
* Use PNG (not JPEG) for better quality on the store.
* The banner and icon designs should share a consistent, simple look.
